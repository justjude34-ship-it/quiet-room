# Quiet Room

A quiet daily companion on your phone. Mood, talk, journal, breath, 5-4-3-2-1, and one tiny next step.

Local-first. No account. Not therapy. Not a crisis service. Buy once, own forever.

Standalone rebuild of Nest Light under a new name. Nest Light is unchanged.

## Use it

Open `index.html` on HTTPS, or Add to Home Screen. Everything stays in this browser (`quietroom.v1` in localStorage).
